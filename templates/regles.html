Comment utiliser ExamPlanner ?

Suivez les etapes ci-dessous pour planifier vos examens en quelques clics.

1
Creer un etablissement

Commencez par creer votre etablissement (ex: : Universite de Tlemcen).

  • Allez dans la section Etablissement dans le menu a gauche
  • Cliquez sur Ajouter et remplissez le nom et l'adresse
  • Un code de 6 caracteres sera genere automatiquement — notez-le !
  • Pour activer cet etablissement, cliquez sur Selectionner et entrez le code
Important : Sans etablissement actif, aucune donnee ne peut etre saisie. Chaque etablissement est isole : vos donnees ne sont visibles que par vous.
2
Saisir les donnees

Une fois l'etablissement actif, remplissez les donnees de base :

  • UE (Unites d'Enseignement) : Ajoutez chaque matiere avec son code et son filia
  • Etudiants : Ajoutez les etudiants, puis inscrivez-les aux UE concernees
  • Salles : Definissez les salles disponibles avec leur capacite
  • Creneaux : Ajoutez les creneaux horaires (jour + heure debut/fin)
Ordre conseille : UE → Etudiants → Inscriptions → Salles → Creneaux
3
Definir les contraintes

Precisez les regles a respecter :

  • Conflits : Deux UE qui ne peuvent pas avoir lieu au meme creneau (ex: meme filiere)
  • Interdictions : Un prof ne peut pas surveiller deux salles au meme creneau
Astuce : Les conflits sont aussi generees automatiquement si deux UE partagent des etudiants ou le meme professeur.
4
Visualiser le graphe

Le systeme construit automatiquement un graphe de conflits :

  • Chaque noeud = une UE
  • Chaque arete = conflit entre deux UE (ne peuvent pas etre au meme creneau)
  • Consultez la matrice d'adjacence et la liste d'adjacence
Concept : Ce graphe est le fondement de l'algorithme de coloration. Plus le graphe est dense, plus il faudra de couleurs (= creneaux).
5
Comparer les colorations

Lancez les deux algorithmes pour comparer :

  • Welsh-Powell : Algorithme glouton rapide, trie par nombre de contraintes
  • DSATUR : Plus precis, choisit le noeud avec le plus de saturation
  • Vous verrez le temps d'execution de chaque algorithme
  • Le nombre de couleurs (= nombre de creneaux utilises) est affiche
Choisissez l'algorithme qui donne le moins de couleurs pour un planning plus compact.
6
Generer le planning

Cliquez sur Generer le planning :

  • Le systeme affecte automatiquement les salles en fonction de la capacite
  • Les creneaux reels (jour + heure) sont affiches
  • Le planning est verifie : filiere eloignee, charge equilibree, aucune interdiction violee
  • Vous pouvez relancer la generation pour trouver un meilleur resultat
Verification : Le systeme vous indique si des alertes existent (creneau surcharge, filiere proche, etc.)
7
Telecharger et exporter

Exportez votre planning :

  • CSV : Tableau au format Creneau x Salle, pret a etre imprime ou partage
  • PDF : Document formate avec en-tete colore, pret a imprimer
  • Les deux formats sont accessibles depuis la page Planning
Finalise ! Vous avez un planning d'examens optimise, sans conflits, et pret a etre communique.
